# 业务范围

## 一、三大板块（原文）

### 设计
- 城市照明规划与设计
- 建筑照明设计
- 景观照明设计
- 室内照明设计
- 灯具设计

### 咨询
- 照明应用与产品咨询
- 照明策划咨询
- 室内外照明后评估咨询
- 自然采光分析咨询
- 夜间光污染评估咨询

### 研究
- 照明专题应用研究
- 材料对照明的影响
- 照明与空间体验
- 光健康研究
- 照明对情绪调节的研究

## 二、八项服务清单（原文，含配图）

| 序号 | 服务项 | 说明 |
| --- | --- | --- |
| 01 | 建筑照明 | 建筑立面与体量的照明设计 |
| 02 | 景观照明 | 城市与园区景观照明 |
| 03 | 室内照明 | 观演、展陈、办公等室内空间照明 |
| 04 | 照明规划 | 城市级/园区级照明专项规划 |
| 05 | 自然光分析 | 自然采光模拟与评估 |
| 06 | 照明策划 | 照明项目的策划与咨询 |
| 07 | 照明后评估 | 建成后的照明效果与能耗评估 |
| 08 | 专题研究 | 光健康、情绪调节、材料与光等专题研究 |

## 三、解读

这张业务范围图透露了两个不太常见的信息：

1. **「研究」是与「设计」「咨询」并列的第三大板块**，且研究选题直指
   「照明与空间体验」「光健康」「照明对情绪调节的研究」——
   这类偏人因与感知的课题，正是互动/体验类灯光项目的理论底座。
2. **「照明后评估」被单列为一项服务**，说明团队把照明视为可验证、可度量的工程对象，
   而非一次性的艺术表达。这与「建筑化照明」的理念互为支撑。
