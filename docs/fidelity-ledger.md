# 视觉一致性验收记录

对照基准：`docs/design/hero.png`。浏览器实现截图：`docs/qa/home-desktop.png`、`docs/qa/home-mobile-final.png`、`docs/qa/lab-desktop-final.png`。

## 五点对照

1. **文案**：品牌名称、主标题、中文主张、作品入口和主导航均与确认稿一致；没有加入确认稿以外的装饰英文。
2. **结构**：桌面首屏保留左侧主张、右侧建筑光廊和下方作品预告；移动端重排为单列，并将菜单折叠。
3. **色彩与光感**：近黑背景、暖白文字、暖金交互色和墙片边缘光保持一致；首屏使用确认稿资产，避免重新生成造成偏差。
4. **字体与比例**：主标题保持轻字重和大字号，中文使用系统无衬线回退；桌面浏览器的首屏裁切会随 16:9 视口略有变化。
5. **交互与状态**：首次会话开场可跳过，首屏保留轻微视差；触屏关闭磁吸指针，390px 视口下按钮、标题和下一段入口均未溢出。

## 验证方法

- 使用 Codex 内置浏览器检查桌面首页、Light Lab 和 390×844 移动端首页。
- 使用图像检查工具逐张比对确认稿与浏览器截图。
- 使用 Playwright 在 1440×900 与 390×844 两套视口验证导航、筛选、项目详情、实验状态、重置和 404。

## 有意保留的差异

- 浏览器实现根据视口动态裁切首屏背景，因此下方 `SELECTED WORK` 的露出高度可能与静态概念图不同。
- 字形由用户设备可用的中文无衬线字体决定，字面宽度可能有少量差异。
- 移动端采用独立响应式布局，重点是可读性和触控操作，不按桌面稿等比缩小。
